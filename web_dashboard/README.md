<h1>Web App Platform</h1>


<h2>How to host the application on your local device</h2>

Download all libraries in the requirements.txt file. 

In terminal, run 'python3 main.py' or 'python main.py' and click on the local server link.

The main dashboard code is the file templates/index.html with all the interactive graphs and filter buttons. 

The supporting javascript functions to display, aggregate, and filter the data is stored in static\js\dashboard-functions.js
